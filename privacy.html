PawPlay Privacy Policy

Effective date: October 6, 2026

PawPlay processes YouTube player state and extension data locally in the browser. No browsing data or other user data is transmitted to or received by the developer through PawPlay.

Data stored on the device

PawPlay uses chrome.storage.local to save the extension's enabled state, selected pet and color, pet names, active watch time, levels, earned coins, level reward records, purchased items, and equipped accessories and effects. This information stays in the Chrome profile on the device and is not stored through chrome.storage.sync.

PawPlay does not store video titles, video URLs, browsing history, search terms, or the content of videos. Among playback-related information, it stores only the local active watch time needed for pet progress and rewards.

YouTube page access

PawPlay runs on https://www.youtube.com/* so it can place the pet next to the video controls and detect local player state, including play, pause, buffering, seeking, advertisements, ordinary video duration, and unsupported live playback. This processing happens on the device. Video titles and URLs are not sent to the developer or to a server.

Network activity and third parties

PawPlay has no account system, analytics, telemetry, advertising, external API, or developer-operated server. It does not transmit extension data to the developer or third parties. It does not offer real-money payments.

Product website

The PawPlay product website is hosted on GitHub Pages. Visiting the website is subject to GitHub's hosting practices described in the GitHub Privacy Statement. The website does not load analytics or tracking scripts and does not receive data from the PawPlay extension.

Limited use

PawPlay uses locally handled data only to provide the visible pet, progression, and cosmetic collection features. It complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is not sold, used for advertising, transferred to third parties, or used for creditworthiness or lending decisions.

Control and deletion

Settings can be changed in the extension popup. Removing PawPlay from Chrome deletes its extension storage under Chrome's normal extension removal behavior. Removing and reinstalling the extension starts it again with fresh local data.

Changes

If PawPlay's data practices change, this policy will be updated before the changed behavior is released. The effective date above identifies the current version of this policy.

Contact

For questions about this policy, open an issue at PawPlay support. GitHub issues are public, so do not include private browsing data, passwords, or other sensitive information.
