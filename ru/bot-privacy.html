Конфиденциальность бота PawPlay

Обновлено: 11 октября 2026

Область действия

Политика относится к @pawplay_purchase_bot. Расширение продолжает хранить имена питомцев, прогресс просмотра и игровые монеты в локальном профиле Chrome. Эти данные расширения не отправляются боту.

Получаемые данные

Telegram передает боту user ID, chat ID, язык и входящие команды или сообщения. Обновления также могут содержать имя и username Telegram. Они временно хранятся в очереди до обработки, затем удаляются из нее. Для заказов сохраняются user ID, язык, идентификатор заказа, цена, валюта, время согласия и покупки, идентификатор платежа, статус оплаты/возврата и выдачи. Данные карты и пароль Telegram мы не получаем.

Цель и хранение

Записи заказов нужны для проверки оплаты, выдачи и восстановления ключа, возвратов, предотвращения повторной обработки платежей и разбора спорных обращений. Заказы и очередь обновлений хранятся на сервере бота в зашифрованном виде, ключ шифрования хранится отдельно. Доступ ограничен оператором. Бот не использует аналитику и не продает данные покупателей.

Срок хранения и удаление

Данные покупок сохраняются, пока нужны для восстановления ключа, возврата, спора или выполнения обязательных требований. Непринятое предложение заменяется при запуске новой покупки. Через поддержку можно запросить доступ, исправление или удаление данных. Ненужные данные удаляются; сведения, необходимые для платежного спора или по закону, могут сохраняться для этой цели. После удаления записи покупки восстановление через /key может стать невозможным.

Поддержка и внешние сервисы

Telegram обрабатывает сообщения и оплату Stars по собственной политике. Форма поддержки размещена в Google Forms: ее содержание, включая необязательный email для ответа и сведения о покупке, получает Google и разработчик. Они используются для разбора обращения и ответа по вашему запросу. Сайт размещен на GitHub Pages. Публичные GitHub issues подходят для несекретных ошибок; сведения о покупке отправляйте через форму.
