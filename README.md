# PawPlay website

Public product website and privacy policy for PawPlay, an independent Chrome extension with pixel pets for YouTube.

- Website: https://n23eos.github.io/pawplay-site/
- Russian: https://n23eos.github.io/pawplay-site/ru/
- Privacy: https://n23eos.github.io/pawplay-site/privacy.html
- Support: https://github.com/n23eos/pawplay-site/issues

Static HTML and CSS with local images. No scripts, tracking, external fonts, or build dependencies. GitHub Pages serves the main branch from its root. This repository contains only the website and public images, not the extension source.
