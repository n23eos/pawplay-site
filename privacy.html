PawPlay Privacy Policy

Effective date: October 7, 2026

PawPlay processes YouTube player state and extension data locally in the browser. It does not automatically transmit browsing data or stored extension data. If you choose to open and submit the external feedback form, the developer can receive the information you voluntarily provide there.

Data stored on the device

PawPlay uses chrome.storage.local to save the extension's enabled state, selected pet and color, selected progress bar style, pet names, active watch time, levels, earned coins, level reward records, purchased items, equipped accessories and effects, and a Boolean showing whether PawPlay Plus is activated in this installation. The purchase key is checked locally and is not stored.

For reliable updates and restores, PawPlay can keep local migration and pre-restore recovery snapshots. It also keeps a bounded watch-credit session ledger with random session identifiers, Chrome tab, window, and document identifiers, sequence and status values, timestamps, and credited seconds. These records do not contain video titles or URLs and remain in the extension's local storage.

PawPlay does not store video titles, video URLs, browsing history, search terms, or the content of videos. Among playback-related information, it stores only the local active watch time and session data needed to preserve progress and prevent duplicate rewards.

When you choose Save backup, PawPlay prepares a JSON file containing settings, pet names, progress, coins, purchases, and equipped items. The manual backup does not contain the Plus purchase key, Plus activation status, video titles, or video URLs. You control the downloaded file and where it is kept.

YouTube page access

PawPlay runs on https://www.youtube.com/* so it can place the pet next to the controls of ordinary videos and detect local player state, including play, pause, buffering, seeking, advertisements, and video duration. The pet and watch credit are unavailable on Shorts, live streams, and embedded players. This processing happens on the device. Video titles and URLs are not sent to the developer or to a server.

Network activity and external services

PawPlay has no account system, advertising, automatic analytics or telemetry, external API, or developer-operated server. It does not automatically transmit extension data to the developer or third parties.

The popup contains links to an optional PawPlay Plus product on Ko-fi and a feedback form on Google Forms. PawPlay Plus is a one-time $1.99 purchase made outside the extension. Ko-fi handles the purchase and key delivery. When you choose either link, the external page opens in a new tab and is governed by that service's privacy practices. PawPlay does not attach its stored extension data to these links. Information entered on Ko-fi is provided to Ko-fi. A report type, description, optional reproduction steps, environment details, and optional email address that you enter and submit through Google Forms are received by Google and made available to the developer as the form recipient. The developer uses that information only to investigate the report, provide support, and reply when requested. Key verification and activation happen locally after you enter the key in PawPlay.

Product website

The PawPlay product website is hosted on GitHub Pages. Visiting the website is subject to GitHub's hosting practices described in the GitHub Privacy Statement. The website does not load analytics or tracking scripts and does not receive data from the PawPlay extension.

Limited use

PawPlay uses locally handled data only to provide the visible pet, progression, cosmetic collection, backup, and local activation features. It complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Stored extension data is not sold, used for advertising, transferred to third parties, or used for creditworthiness or lending decisions.

Control and deletion

Settings can be changed in the extension popup. You can manually save or restore a progress backup there. The backup is not a Plus license backup, so keep the purchase key separately if you need to activate Plus again. Removing PawPlay from Chrome deletes its extension storage, including local recovery snapshots, the session ledger, and activation status, under Chrome's normal extension removal behavior. A downloaded backup file remains wherever you saved it.

Changes

If PawPlay's data practices change, this policy will be updated before the changed behavior is released. The effective date above identifies the current version of this policy.

Contact

For questions about this policy, open an issue at PawPlay support. GitHub issues are public, so do not include private browsing data, passwords, or other sensitive information.
